# User guide

1. Start a voice session in the browser console and choose the response language.
2. Say or type the city, purpose, budget, and area. Awaaz returns only verified available matches.
3. Ask for a property detail; source-backed facts include price, payment plan, amenities, schools,
   and hospitals.
4. Use the consented visit form to select a 30-minute PKT slot. The assigned employee is derived
   from inventory and cannot be overridden by the model. An optional phone number is encrypted and
   shared only with the appointment delivery integrations.
5. For selling or uncertain requests, submit the human handoff form and optionally choose a
   follow-up reminder. Do not enter secrets or unconsented personal information into the conversation.
